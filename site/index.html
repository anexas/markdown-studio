Built for writing, not configuring

Everything you need to write and read Markdown, and deliberately nothing else.

Three view modes

Raw source with CodeMirror 6 highlighting, split view with synchronised scrolling, or a clean preview. Ctrl+E cycles them.

An editable rendered pane

The right side of Split is not a picture: type in it. Enter continues a list, Tab nests it, Ctrl+B and Ctrl+I toggle bold and italic, and task boxes are clickable. Tables and raw HTML stay byte-for-byte as raw blocks, and Ctrl+Alt+P flips the pane to a faithful read-only preview.

Maths and diagrams

$E = mc^2$ inline and $$ … $$ blocks are typeset with KaTeX in the preview, the rendered pane and exports. A fenced block tagged mermaid draws a flowchart or sequence diagram in place, and Mermaid loads only when a document actually contains one.

Nothing gets lost

A saved file is written about a second after you stop typing, and before a tab or the window closes. If another program rewrites the file, a clean tab follows it and a tab with unsaved edits asks first — reload the file, or keep yours.

Export that stands alone

Ctrl+Shift+E writes one HTML page: styles inlined, images embedded, maths typeset and diagrams drawn. Point Preferences at your own CSS file and the pane and the page both pick it up.

GFM rendering

Tables, task lists, footnotes, heading anchors and fenced code with language highlighting, rendered as you type.

Untrusted input, by default

Rendered HTML is sanitised with DOMPurify under a strict content security policy, remote images are blocked instead of fetched, and saves are atomic — temp file, flush, rename.

Tabs that remember

Dirty markers, middle-click close, and your whole session restored on relaunch. Ctrl+N reuses an untouched empty tab instead of stacking blanks.

Folder sidebar

A read-only tree of Markdown files that follows the document you are editing, with a breadcrumb bar that opens any folder above it.

Native Windows shell

A real Win32 menu bar with accelerators, native file dialogs, drag-and-drop, single instance and remembered window geometry.

Text zoom, print, export

Zoom the text from 60 % to 240 % without the chrome reflowing, and print straight to PDF with a print stylesheet.

No account, nothing uploaded

No telemetry, no sign-in, no sync. Files are read and written locally by a handful of Rust commands that validate extension, size and path first.

The ones you will actually use

Installing

Download the MSI, run it, and Markdown Studio takes over as the handler for Markdown files.

What the installer does

Installs per-machine into Program Files, so it asks for elevation once. It registers .md, .markdown, .mdown and .mkd, adds an entry to Add or remove programs, and ships its full third-party notices alongside the executable.

Windows 10 or 11 on x64. WebView2 is preinstalled on Windows 11 and already present on nearly every Windows 10 machine.

How it treats your files

Markdown is treated as untrusted input: rendered HTML is sanitised with DOMPurify under a strict content security policy, and remote images are blocked rather than silently fetched.

Saves are atomic — written to a temporary file, flushed, then renamed over the target — and files keep the BOM state and line endings they were opened with.
